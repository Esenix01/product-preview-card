# Product Preview Card

My solution to the Product Preview Card challenge from Frontend Mentor. This is the first time I built something from a design, so I matched my page against the design images as closely as I could.

## What I learned
- Setting up a two-column card with CSS Grid
- Swapping the image on mobile with the picture element
- Loading fonts from Google Fonts (I forgot a comma and my title stayed in Times New Roman for a while)
- Writing a media query so the card stacks on phones

## What I'd improve
- Match the spacing more exactly
- Add a cart icon to the button
